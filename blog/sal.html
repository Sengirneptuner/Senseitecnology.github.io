¿Qué es Salvium?

Salvium parte del código de Monero y explora la combinación de privacidad + funciones de compliance (orientado a ser compatible con requisitos regulatorios). Mina con RandomX por herencia directa de Monero. Es un proyecto joven: pool, exchanges y liquidez pueden cambiar rápido.

⚠ Proyecto de liquidez muy baja y poco recorrido. Verifica algoritmo vigente, pools existentes y estado de retiros. Trata los precios referenciales con escepticismo: el spread real puede ser grande.

2 · Setup en PC▸

Por herencia CryptoNote/RandomX, XMRig suele ser compatible: consulta los pools listados por el proyecto y ajusta puerto/dirección:

./xmrig -o POOL_DE_SAL:PUERTO \
  -u TU_DIRECCION_SAL -t 4

Wallet desde salvium.io o el repo oficial del proyecto.

3 · Setup en Termux (Android)▸

Misma familia RandomX: compila XMRig en Termux y apunta al pool vigente.

pkg update && pkg install git cmake clang make -y
git clone https://github.com/xmrig/xmrig.git
cd xmrig && mkdir build && cd build
cmake .. && make -j2
./xmrig -o POOL_DE_SAL:PUERTO -u TU_WALLET -t 2

⚠ Con monedas tan pequeñas, calcula primero si el ingreso/día justifica el desgaste del móvil.

5 · Rentabilidad: cómo calcularla▸

Beneficio neto diario = ingreso bruto − (kW × 24 × $/kWh) − comisiones de pool − otros.

Los proyectos pequeños pueden pagar mejor en teoría (menos competencia de hashrate) pero el riesgo de precio/liquidez es mucho mayor: dimensiona la posición para poder salir.

⚠ Guía educativa. Precios, algoritmo y disponibilidad de exchanges cambian. Verifica siempre en fuentes oficiales antes de enviar fondos.
