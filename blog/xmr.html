¿Qué es Monero?

Monero es la moneda de privacidad más grande y líquida del ecosistema CPU. Su PoW, RandomX, fue diseñado específicamente para CPU: usa un scratchpad de 2 MB que cabe en la caché L3, ejecución aleatoria de instrucciones y verificación de memoria, de modo que GPU y ASIC no tienen ventaja práctica. Es la referencia contra la que se compara todo lo demás.

⚠ RandomX en modo completo usa ~2 GB de RAM por hilo en fast mode; en light mode rinde menos. Verifica también la regulación de XMR en tu jurisdicción: algunos exchanges restringen su comercio.

2 · Setup en PC▸

Lo más simple: descarga XMRig precompilado desde releases. Para compilarlo:

git clone https://github.com/xmrig/xmrig.git
cd xmrig && mkdir build && cd build
cmake .. && make -j$(nproc)

Ejecuta contra un pool (ejemplo SupportXMR) o mina solo vía P2Pool:

./xmrig -o pool.supportxmr.com:3333 \
  -u TU_DIRECCION_XMR -t 4

P2Pool es la vía descentralizada: corres monerod + p2pool local y minas a tu propio nodo, sin registros ni comisiones centralizadas.

3 · Setup en Termux (Android)▸

RandomX funciona en Termux pero es intensivo: móvil de ≥6 GB RAM, 1–2 hilos y vigilancia de temperatura.

pkg update && pkg upgrade -y
pkg install git cmake clang make -y
git clone https://github.com/xmrig/xmrig.git
cd xmrig && mkdir build && cd build
cmake .. && make -j2
./xmrig -o pool.supportxmr.com:3333 \
  -u TU_DIRECCION_XMR -t 2

⚠ Sin huge pages en Android el hashrate cae bastante. Usa solo 1–2 hilos; el uso prolongado degrada la batería.

Monero tiene la mayor liquidez de la categoría CPU: cotiza en exchanges grandes y en swaps no custodiales. Verifica la disponibilidad exacta en tu país/jurisdicción antes de vender cantidades grandes.

5 · Rentabilidad: cómo calcularla▸

Beneficio neto diario = ingreso bruto − (kW × 24 × $/kWh) − comisiones de pool − otros.

XMR es el mejor termómetro: compara tu hash/s con el de la red en sitios tipo miningpoolstats antes de comprometer hardware. La volatilidad es menor que en monedas pequeñas, pero el margen por watt también.
