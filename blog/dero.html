¿Qué es DERO?

DERO es una blockchain de privacidad con contratos inteligentes y firmas homomórficas. Su PoW es AstroBWT, un algoritmo memory-hard diseñado para favorecer CPU sobre ASIC/GPU. Usa Salsa20 + SHA3 + transformaciones dependientes de la cadena.

⚠ Antes de minar: verifica el ticker exacto, el estado de la red, depósitos/retiros en el exchange y el algoritmo vigente (puede cambiar por hard fork). No reutilices configuraciones de XMR en DERO.

2 · Setup en PC (Linux)▸

Descarga el monedero y el minero oficiales desde el repo:

git clone https://github.com/deroproject/derohe.git
cd derohe
make
./derod --rpc-bind=127.0.0.1:10102
./dero-wallet-cli --generate

Luego ejecuta el minero apuntando a tu wallet:

./dero-miner \
  --daemon-address=127.0.0.1:10102 \
  --wallet-address=TuDireccionDERO... \
  --mining-threads=4
3 · Setup en Termux (Android)▸

Termux puede compilar el minero, pero AstroBWT es intensivo: usa un móvil con ≥6 GB RAM y buena refrigeración.

pkg update && pkg upgrade -y
pkg install git cmake make clang curl -y
git clone https://github.com/deroproject/derohe.git
cd derohe
make -j2
./dero-miner --daemon-address=community-pools.mysrv.cloud:10300 \
  --wallet-address=TuDireccionDERO... \
  --mining-threads=2

⚠ En Termux usa solo 1–2 hilos y vigila la temperatura. Un uso prolongado degrada la batería.

4 · Dónde comprar / vender DERO▸

Verifica siempre la pestaña Markets en CoinGecko/CoinMarketCap antes de operar. Exchanges habituales: TradeOgre, NonKYC, Hotbit (verificar estado). La liquidez es menor que XMR: revisa profundidad antes de vender cantidades grandes.

5 · Rentabilidad: cómo calcularla▸

Beneficio neto diario = ingreso bruto − (kW × 24 × $/kWh) − comisiones de pool − otros.

Mide el consumo en la pared, no el TDP. Compara con tu factura eléctrica local. DERO es volátil y de baja liquidez: separa "puedo minar" de "puedo vender".

⚠ Guía educativa. Precios, algoritmo y disponibilidad de exchanges cambian. Verifica siempre en fuentes oficiales antes de enviar fondos.
